# 株式会社アスノテ名古屋 コーポレートサイト

愛知県・名古屋市周辺の中小企業を支援する、架空のDX・業務改善会社のコーポレートサイトです。中小企業向けホームページ制作案件への応募を想定した自主制作ポートフォリオとして制作します。

> 本サイトはポートフォリオ用に制作する架空企業のデモサイトです。企業情報、導入事例、成果数値、連絡先はすべて架空の内容です。
