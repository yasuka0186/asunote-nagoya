# ポートフォリオ掲載文

## 株式会社アスノテ名古屋 コーポレートサイト

愛知県・名古屋市周辺の中小企業を支援する架空のDX・業務改善会社を題材にした、自主制作のコーポレートサイトです。ITに詳しくない担当者にもサービス内容と支援後の変化が伝わり、問い合わせへ迷わず進めることを目的に、要件定義、デザイン、実装、テスト、公開まで行いました。

9ページをモバイルファーストで制作し、スマートフォンメニュー、FAQ、共通データによる事例・お知らせ表示、入力・確認・完了の3段階フォームをJavaScriptのES Modulesで実装しています。フォームでは必須・形式・文字数・同意の検証、エラー表示、フォーカス移動、入力保持まで確認でき、実際の送信を行わないデモであることも明記しました。

見た目だけでなく、キーボード操作、フォーカス表示、動きの抑制、構造化データ、OGP、canonical、画像最適化、公開用ファイルの圧縮にも対応しています。VitestとPlaywrightによる自動テスト、HTML・JavaScript・SCSSの検証、複数画面幅での手動確認を実施しました。公開URLでの最終LighthouseはPerformance 99、Accessibility 100、Best Practices 100、SEO 100です。

- 公開サイト：<https://yasuka0186.github.io/asunote-nagoya/>
- ソースコード：<https://github.com/yasuka0186/asunote-nagoya>
- 使用技術：HTML、SCSS、JavaScript（ES Modules）、Vitest、Playwright、GitHub Actions、GitHub Pages

本制作はクライアントワークではなく、企業情報、事例、成果数値を含むすべての内容が架空です。これまでのWebアプリケーション開発、テスト、手順書作成、不具合調査の経験を、状態を意識したUI実装、再利用可能なデータ構成、完了条件に基づく品質確認へ活かしました。AIは要件整理、文章案、レビューの補助に活用し、最終判断、調整、実装内容の確認、動作確認は制作者自身が行っています。
