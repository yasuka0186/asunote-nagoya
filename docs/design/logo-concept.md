# ロゴSVG案

## コンセプト

- 左下から右上へ伸びるラインで「明日」と「成長」を表す。
- ラインに沿う曲線で、企業の隣を走る「伴走」を表す。
- 2本の線が同じ方向へ進む形にし、単色でも意味が失われない。
- 小さい表示でも判別できるよう、細かな装飾やグラデーションは使わない。

## 構成

- シンボル：48px四方を基準に設計。
- ロゴタイプ：「アスノテ名古屋」をシンボルの右側へ配置。
- メインカラー：ネイビー `#15324B`。
- 成長ライン：濃い青緑 `#0B6E70`。
- SVGにはグラデーション、影、外部フォント読み込みを含めない。

## 利用方針

- ヘッダーとフッターでは`assets/svg/logo-concept.svg`を使用候補とする。
- 外部画像として使う場合は、HTML側で会社名を含む代替テキストを設定する。
- SVGをインライン配置する場合は、重複する読み上げを避けてアクセシブルネームを一元化する。
- 最終ロゴの確定と必要な表示バリエーションの整理は、Day 3の素材準備で行う。
