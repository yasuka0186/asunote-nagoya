# 制作タスク計画

## スコープ

- 制作ページは要件定義書で確定した9ページとする。
- URLは要件定義書「11-4. URL・パス設計」に従う。
- 対象外は要件定義書「19. 対象外」に従い、制作途中で独断追加しない。
- 全体の完了条件は要件定義書「21. 受入条件」と一致させる。

## 13工程

| Day | フェーズ | 完了条件 |
|---|---|---|
| 1 | 要件確定・準備 | 9ページと対象外を確定し、GitHubで作業開始できる |
| 2 | ワイヤー・デザイン設計 | トップ・下層の配置とデザイントークンを確定する |
| 3 | 原稿・素材準備 | 完成原稿、必要素材、ライセンス情報をそろえる |
| 4 | 基盤実装 | 共通レイアウトを全ページで表示する |
| 5 | トップ実装 | トップページをPC・スマートフォンで閲覧できる |
| 6 | サービス・会社案内 | 2ページを完成させ、トップから遷移できる |
| 7 | 事例・お知らせ | 共通データの再利用と表示分岐を動作させる |
| 8 | フォーム | 正常系・異常系を手動で最後まで確認できる |
| 9 | 補助機能・補助ページ | 全9ページと主要JavaScript機能をそろえる |
| 10 | レスポンシブ・ブラウザ調整 | 指定幅で重なりや不要な横スクロールを解消する |
| 11 | SEO・性能 | SEO項目をそろえ、Lighthouse初回結果を記録する |
| 12 | テスト・修正 | 自動テストとlintを成功させ、重大な不具合を0件にする |
| 13 | 公開・仕上げ | 公開サイトと全成果物を第三者へ提示できる状態にする |

各工程の詳細チェックリストは要件定義書「23. 日別チェックリスト」を正とする。
